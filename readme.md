# BF-Manager

BF-Manager adalah aplikasi Android File Manager dengan target feature parity terhadap MT Manager 2.26.11. Seluruh fitur ditargetkan tersedia gratis tanpa login akun BF Manager, subscription, atau paywall.

## Dokumentasi

Mulai dari [Peta Dokumentasi](docs/README.md) untuk melihat spesifikasi, inventaris fitur, kriteria penerimaan, hasil audit referensi, dan aturan pemeliharaan dokumentasi.

## Status

Audit referensi dan spesifikasi arsitektur sedang berlangsung. Klaim feature parity hanya dapat dibuat setelah seluruh Feature ID diimplementasikan dan lulus acceptance test.
